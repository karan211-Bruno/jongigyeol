종이결 1.0.0 — 설치 안내
================================

패키지 이름: app.jongigyeol.note
버전: 1.0.0
지원: iPadOS 15 이상, Android 7.0(API 24) 이상

[Android APK]
파일: jongigyeol-1.0.0-android.apk
1. APK를 태블릿으로 옮깁니다.
2. 파일 관리자에서 APK를 열고 설치를 누릅니다.
3. 처음 한 번만 "출처를 알 수 없는 앱 설치 허용"을 켭니다.
4. 홈 화면의 종이결 아이콘으로 실행합니다.
※ 릴리스 키로 서명되어 있어 바로 설치할 수 있습니다.

[iPad / iOS]
파일: jongigyeol-1.0.0-ios-unsigned.ipa
이 파일은 Apple 서명이 없는 상태입니다. 아래 중 하나로 본인 Apple ID 서명 후 설치하세요.

방법 1 — Xcode (무료 Apple ID 가능)
1. ios/App/App.xcodeproj 를 Xcode로 엽니다.
2. App 타깃 → Signing & Capabilities → Team에서 본인 Apple ID 선택.
3. Bundle Identifier가 중복이면 app.jongigyeol.note 를 조금 바꿉니다.
4. iPad를 연결하고 Run(⌘R).
※ 무료 계정은 7일마다 다시 서명해야 합니다.

방법 2 — Sideloadly / AltStore
1. Sideloadly 실행 → IPA 선택 → Apple ID 입력 → Start.
2. iPad의 신뢰 설정에서 개발자를 신뢰합니다.
※ 무료 계정은 7일 제한이 있습니다.

[서명 키]
Android APK는 릴리스 키로 서명되어 있습니다. 서명 키와 비밀번호는 보안상 이 배포 폴더에 포함하지 않았습니다.
키를 잃으면 기존 Android 앱을 업데이트할 수 없으므로 별도로 안전하게 보관하세요.

[무결성 확인]
SHA256SUMS.txt 참고.
  shasum -a 256 jongigyeol-1.0.0-android.apk
  shasum -a 256 jongigyeol-1.0.0-ios-unsigned.ipa

[데이터]
노트와 필기는 기기의 IndexedDB에만 저장됩니다. 앱을 삭제하기 전에 설정 → 데이터 → 전체 백업으로 JSON을 내려받으세요.
